# Markdown 表格（GFM）速查

## 基本形

管道表格 = 表头行 + 分隔行 + 数据行，列以 `|` 分隔：

```markdown
| 命令       | 作用     | 示例       |
| ---------- | -------- | ---------- |
| `/reload`  | 重载插件 | `/reload`  |
| `/plugins` | 插件面板 | `/plugins` |
```

## 对齐控制

分隔行冒号位置决定列对齐（缺省左对齐）：

- `:---` 左对齐（缺省）
- `:---:` 居中
- `---:` 右对齐（数值列常用）

## 常见坑

- **竖线转义**：单元格内写字面 `|` 须用 `\|`；代码 span 内的 `|` 同样要转义。
- **表格内无块级元素**：一个单元格不能容纳代码块或列表——需要时改用 HTML `<table>` 或把细节挪到表后小节。
- **列宽无关**：渲染列宽由内容决定，源码里的空格数不影响输出——但保持源码列宽一致利于 diff 审读。
- **表头不可省**：GFM 表格必须有表头行；无表头需求时首行写空单元格或加粗占位。
